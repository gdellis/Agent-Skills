# Research & Synthesis Skill

## When to use

Activate when the user wants to combine multiple known sources into a coherent brief, comparison, recommendation, or decision memo. This is strongest when sources are already provided or when the research is bounded.

Prefer `deep-research` for broad open-ended investigations, market landscapes, state-of-the-art reports, or any request that requires many fresh searches and a full research report canvas.

## Approach

### Step 1: Scope the research

1. Clarify the research question (what exactly do we want to know?)
2. Define boundaries (which competitors/options? time period? geography?)
3. Agree on output format (summary doc, comparison table, presentation)
4. Identify available sources (web search, internal docs, connectors)

### Step 2: Gather information

1. Read user-provided files, links, notes, canvases, or tool results first
2. Search the web for current public information when needed
3. Use internal search or connected document tools for private workspace information when relevant
4. For each source, extract: key facts, claims, data points, and short quotes when useful
5. Track source attribution for every important claim

### Step 3: Structure the analysis

1. Organize by theme/dimension, not by source
2. Create comparison frameworks (tables, matrices)
3. Identify patterns, consensus, and contradictions across sources
4. Separate facts from opinions from speculation

### Step 4: Synthesize and recommend

1. Executive summary (3-5 bullet points with the key takeaways)
2. Detailed findings organized by theme
3. Comparison table (for competitive/benchmarking analyses)
4. Implications: "so what?" — what does this mean for us?
5. Recommendations: what should we do next?

## Quality standards

- Every factual claim must cite a source
- Clearly distinguish between verified facts and estimates
- Present multiple perspectives, not just the first result
- Flag when information is outdated, uncertain, or potentially biased
- If the user wants an editable or shareable deliverable, create a canvas in the most appropriate format
